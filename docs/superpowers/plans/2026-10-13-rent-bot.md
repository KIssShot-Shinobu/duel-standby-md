# Fitur Rent (Sewa Bot per Grup) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task, or subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Grup harus "menyewa" bot (1 bulan = 30 hari, bayar ke owner); tanpa sewa aktif, fitur bot di grup dikunci kecuali Yu-Gi-Oh & stiker; penyewa mendapat hak tanpa limit global.

**Architecture:** Pola lama: lib/buy-limit.js (logika murni) + plugin pengguna + plugin owner + hook event. Rent mengikuti pola yang sama: `lib/rent.js` = logika murni (status, activate, gating, sweep, resolve grup), `plugins/rent.js` = command user+owner (`.rent/.sewa/.rentstatus/.renew/.grouplist`), `plugins/_rent-guard.js` = hook `onGroupParticipants` (auto-DM + QRIS saat bot ditambahkan). Gating disuntik di handler.js; limit penyewa di-bypass di handler.js. Sweep berkala di main.js.

**Tech Stack:** Node 20+, Baileys `groupGetInviteInfo`/`groupFetchAllParticipating`/`groupMetadata`, database JSON existing (`db.data.rentals` & `db.data.renters` — section terpisah dari `data.users`).

**Spec:** Desain final disepakati di percakapan: alur sewa (DM → pending → bukti → owner approve → aktif 30 hari → `.renew`), QRIS `assets/qris.jpg`, gating (yugioh+stiker selalu free, sisanya kunci kecuali main-* & rent), grup owner dikecualikan, penyewa unli global, `.grouplist` owner-only.

## Global Constraints

- Durasi sewa = **30 hari** (`Date.now() + days * 86400000`). Harga default dari `config.rent.pricePerMonth`, bisa dioverride permenen via `db.data.settings.rentPrice` (`.rent price`).
- **Gating:** plugin entry diidentifikasi dari `entry.name` (base name file). Free selamanya: nama diawali `game-yugioh`, `tools-sticker`, `sticker-`, `tools-toimg`. Selalu boleh: diawali `main-`, `owner-`, atau `rent.js` / `_rent-guard.js`. Selain itu **dikunci** bila grup tanpa sewa aktif.
- **Grup owner dikecualikan:** tidak dikunci bila ada salah satu nomor owner (`config.bot.owners`, berupa array nomor) yang jadi peserta grup (cocok via `bareNumber`).
- Data penyewa hidup di `db.data.renters` (section terpisah dari `data.users`) — registry `{ [userJid]: { since, name, groups[] } }`. Status unli ditentukan dari `db.data.rentals` (maksimal satu rental aktif per grup, renter otomatis unli global).
- Pesan kunci default (bisa diubah config): `🔒 Fitur ini butuh sewa aktif. Ketik .rent untuk menyewa.`
- QRIS dibaca dari `config.rent.qrisFile` (default `assets/qris.jpg`) relatif `config.root`; gagal baca → hanya teks, tidak crash.
- Tidak ada aksi keluar grup — expired = kunci fitur.

## Review Focus

1. Grup yang **belum pernah** minta sewa (tidak ada record rental) → dianggap unpaid, dikunci. Test di Task 4 (`tidak ada rental`).
2. `.rent` dipakai **di dalam grup** (bukan DM) → harus tetap jalan (info/status), tidak error. Test di Task 5.
3. Penyewa punya rental expired di grup A tapi rental **aktif di grup B** → tetap unli global (sesuai keputusan). Test di Task 4.
4. Invite link **tidak valid/expired** → pesan ramah, bukan throw mentah. Test di Task 3 (`resolveGroupJid`).
5. Owner muncul di grup yang expired → tetap bebas (owner-exempt). Test di Task 4.

export function isGroupGated(db, groupJid, entryName, config, { participants = [], isOwner = false, now = Date.now() } = {}) {
  const s = rentSettings(db, config);
  if (!s.enabled) return false;
  if (isOwner) return false;
  if (isFreePlugin(entryName) || isAlwaysAllowed(entryName)) return false;
  if (ownerInGroup(participants, config)) return false;
  return rentalStatus(db, groupJid, { now }) !== 'active';
}
